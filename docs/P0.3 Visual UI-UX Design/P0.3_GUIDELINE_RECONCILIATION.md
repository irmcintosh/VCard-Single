## 2. Method and classification

Compare source statements with approved product scope and UX first, then with the existing P0.3 design. Apply precedence: P0.1 requirements, P0.2 interactions, compatible original guidelines, then the twelve owner-approved P0.3 choices. Retain compatible visual principles without recreating obsolete conceptual destinations. The guideline supplies no palette hex values, exact dimensions or type scale; those remain the approved P0.3 interpretation, not values attributed to the original source.

**Aligned** means the existing P0.3 specification already expresses the principle. **Clarified** means reference/wording/context is reconciled without changing an approved choice. **Superseded** identifies a conceptual feature/route governed by later P0.1/P0.2 approval. **Conflict** would identify a substantive contradiction not resolved by that precedence and would require stopping for owner review. None remains after comparison. Alignment denotes document agreement, not rendered or tested performance.

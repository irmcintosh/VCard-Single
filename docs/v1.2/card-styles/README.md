# VCard Native V1.2 — Card Style Specification Pack

Place the included `card-styles` directory under `VCard/docs/v1.2/`.

Contains seven per-style `STYLE_SPEC.md` files and `CARD_STYLE_SHARED_RULES.md`. These are **draft implementation specifications** grounded in the approved V1.2 requirements, not seven already approved visual mockups. Each style folder can later hold an owner-approved `REFERENCE.png`.

Suggested workflow: review the descriptions; approve or revise visual composition; then give Codex the combined implementation task with instructions to read all eight files. Classic remains unchanged. No source code, Gradle settings or signing files are changed by this documentation pack.

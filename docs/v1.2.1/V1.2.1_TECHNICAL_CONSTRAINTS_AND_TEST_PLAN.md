# VCard Native V1.2.1 — Technical Constraints and Verification Plan

**Status:** Planning guidance; not evidence of code inspection or testing.

## Project protections

Follow `VCARD_NATIVE_ANDROID_STUDIO_PROTECTION_SKILL.md`: read-only investigation first, report precise files/risks, request approval, then verified external timestamped backups before minimal edits. Preserve package `com.mackseoul.vcardnative`, signing certificate, Gradle/SDK/dependencies, persisted profile format, contact/QR payloads, sharing and widget actions. No schema changes assumed necessary.

## Country-code UI

Inspect current country selector and existing Social Profiles platform selector. Prefer reuse of existing styling/positioning behavior where technically suitable; do not assume the same Compose component supports long lists without constraints. Confirm popup bounds, scroll, IME, accessibility and selection persistence. No new dependency unless separately approved.

## RemoteViews widget

Inspect actual V1.2.0 widget code and all four existing size classes before selecting thresholds. Android launcher grid counts do not equal fixed dp; use reported widget options/bounds as available and ensure responsive behavior on resize. RemoteViews has constraints unlike normal Compose. Avoid speculative API calls or automatic text measurement promises.

Title initials should be generated from the displayed title in memory, without mutating persisted data. Confirm behavior for already-acronym titles and multilingual/punctuation cases before implementation. Maintain name/menu priority and avatar fallback.

# V1.2.1 — Country Dropdown Decision Addendum (Final Plan)

**Owner-approved UX direction (2026-11-05). Not implementation authorization.**

## Decisions
- The country selector uses a read-only outlined anchor styled consistently with Social Profiles → Platform; **do not change the Social Profiles selector**.
- In the **compact side-by-side phone row**, the selected value is displayed as **calling code + ISO region**, e.g. `+44 GB` or `+1 US`. The searchable list retains full localized labels, e.g. `United Kingdom (+44)`. Do not change the persisted ISO region identifier.
- The country list is both **searchable and scrollable**; search supports localized country names and calling codes. The final plan also recommends ISO code matching (e.g. `GB`, `KR`) and accent-insensitive matching where practical. Those two extensions are **proposed**, not independently approved as separate UX decisions; confirm before implementation if material.
- Opening the selector hides an already-visible keyboard and does **not** auto-focus search. Explicitly tapping the search field may show the keyboard.
- The search field remains visible while scrolling results; the popup is bounded and usable near the screen edge and with IME visible.
- Query is transient, resets on dismissal or selection, and never mutates stored profile data.
- Keep existing libphonenumber country data, ISO region selection callback, validation, E.164, persistence and contact export behavior.
- No new dependencies, Gradle, manifest, signing, schema, or unrelated changes.

## Implementation uncertainties
- Material 3 1.3.2 `ExposedDropdownMenu` focusability for an embedded editable search field was **not verified from a source JAR or on device**. Prefer a focusable anchored `DropdownMenu` if necessary; confirm actual behavior by a minimal device check.
- Exact popup width matching, height cap, and text truncation require visual verification in both side-by-side and stacked layouts.
- An additional `strings.xml` search label and no-results message are expected; translate existing locales if present.

## Documentation precedence
This addendum supersedes earlier **scroll-only** assumptions for V1.2.1 M1. It does not replace the full V1.2.1 baseline, nor authorize Kotlin edits.

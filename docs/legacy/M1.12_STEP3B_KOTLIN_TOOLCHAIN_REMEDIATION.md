## 4. Advisory verification

The reviewed [GitHub advisory GHSA-r937-wjx7-w2jp](https://github.com/advisories/GHSA-r937-wjx7-w2jp), also [CVE-2026-53914](https://nvd.nist.gov/vuln/detail/CVE-2026-53914), identifies Kotlin Gradle plugin versions **before 2.4.20-Beta1** as affected by unsafe deserialization in Kotlin build-cache metadata. The first fixed version is `2.4.20-Beta1`; stable `2.4.20` is therefore past the threshold. This remediation uses stable Kotlin `2.4.21`, released as a bug-fix release by [JetBrains](https://kotlinlang.org/docs/releases.html).

An OSV batch query against the versions actually resolved for KGP 2.4.21, Compose compiler Gradle plugin 2.4.21, KGP API/compiler artifacts, and the selected Kotlin runtime returned **no additional published advisories** for the queried coordinates. The GitHub Maven advisory listing for the KGP likewise returned the addressed GHSA. These point-in-time queries do not constitute a complete transitive build-plugin SCA scan or a guarantee against undisclosed vulnerabilities.

Relevant compatibility sources:

* Android's [Kotlin and AGP compatibility table](https://developer.android.com/build/kotlin-support) lists AGP 8.5.2+ for Kotlin 2.4; project AGP 8.10.1 meets that threshold.
* Kotlin's [Gradle plugin variant table](https://kotlinlang.org/docs/gradle-plugin-variants.html) maps the `gradle811` plugin variant to Gradle 8.11–8.12.
* Gradle 8.11.1's [Java compatibility matrix](https://docs.gradle.org/8.11.1/userguide/compatibility.html) supports running Gradle on Java 21.
* Android's [Compose compiler setup](https://developer.android.com/develop/ui/compose/compiler) directs projects using the Compose compiler Gradle plugin to match its version to Kotlin.

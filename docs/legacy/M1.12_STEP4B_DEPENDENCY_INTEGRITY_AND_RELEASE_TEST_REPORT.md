Selected generated hashes were checked against bytes served by the configured artifact repositories. For artifacts without an independently checked publisher checksum/signature chain, bootstrap trust is based on the verified build environment, configured HTTPS repositories, and this reviewed initial resolution. Gradle-generated checksums are not authenticity attestations. No claim is made that every artifact has independently verified provenance.

## 9. Remaining risks and owner decisions

1. **Build-tool dependency advisories:** 3 Critical and 21 High exact version matches in build/plugin transitive components. Owner review is required before any dependency-version remediation. No versions were changed in this step. Do not interpret checksum pinning as remediation of vulnerable dependencies.
2. **Artifact provenance:** strict SHA-256 checksums protect subsequent builds from artifact substitution relative to this reviewed metadata; initial provenance is not independently established for every artifact. Publisher signature-key fingerprints were not validated for the sampled `.asc` files.
3. **FileProvider lifecycle:** actual chooser cancel/completion, task-removal, reboot, direct delete denial, and legitimate grant retention after recipient handoff remain unverified.
4. **Workflow boundary:** release-variant code was exercised by 58 instrumentation tests on each API level, but full manual UI verification against the production `MainActivity` persistence root and external document picker was not performed.
5. **Lint:** 59 warnings, zero errors, same inventory; accepted for this step without cleanup.
6. **Reproducibility:** dependency locking remains absent and is not part of this authorization.
7. **Privacy/cryptography limitations:** app-private storage is not encryption at rest; user-directed backups remain plaintext; checksums do not authenticate the backup author. No private-key generation/export was added.
8. **R8/resource shrinking:** remain disabled and unverified.
9. **Known limitations carried forward:** Android Camera may show literal `\n` in imported Notes; older APKs cannot read schema-3 profiles; physical structured-name exporter verification remains incomplete but owner-accepted for M1.11.

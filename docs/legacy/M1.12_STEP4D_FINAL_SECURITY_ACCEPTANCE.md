## 4. Residual security risks requiring explicit owner acceptance

1. **Build-time dependency exposure:** 3 Critical and 21 High advisory matches affect resolved build/test dependencies. These can execute with build-worker privileges. The scans did not establish vulnerable-code reachability or exploitability, and did not prove such paths impossible.
2. **Artifact trust:** strict verification protects against artifact substitution relative to the committed checksum set; the initial checksum bootstrap is not an independent publisher-authenticity proof.
3. **Signing separation:** production signing credentials must remain isolated from Gradle build workers. Test-signed APKs must not be distributed as production releases.
4. **Future toolchain changes:** review advisories and compatibility for the actual resolved AGP, Gradle, Kotlin, Compose, and test-tool graphs before future upgrades.
5. **Unverified sharing edges:** chooser/recipient lifecycle cases listed above remain untested. Existing targeted access-boundary tests passed; untested lifecycle cases are not evidence of a current defect.

The 59 lint warnings are unchanged and non-blocking. They are not security findings. No dependency fix, signing change, screenshot restriction, R8 change, or application behavior change is proposed by this acceptance report.

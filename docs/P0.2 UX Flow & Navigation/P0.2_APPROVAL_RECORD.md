## Clarification A - Contact QR privacy

- Contact QR is the default sharing mode.
- Display the offline contact QR immediately when valid saved/export-enabled contact data can be encoded, with a readable summary of the included contact information.
- The user may voluntarily open S01 Contact Export Preview before presenting the QR. There is no blocking confirmation before initial QR display.
- Require S01 and explicit action-specific confirmation before generating/sharing a .vcf file.
- Require the same preview and confirmation before saving or sharing a contact QR image.
- Never include fields excluded from contact export.
- Invalidate stale QR previews and artifacts after relevant saved-profile or visibility changes; use current saved data for subsequent display/export.
- Contact field mapping, vCard encoding, QR payload limits and visibility defaults remain P0.4 responsibilities.

This distinction is recorded in the specification's sharing/export sections, F04/F06/F07/F13, the navigation map, P0.2-06 and requirements traceability.

## Clarification B - Appearance image-editing navigation

N04 Edit Profile remains the single location for selecting/editing profile and cover images.

- When N05's image link is requested with unsaved appearance changes, show existing D01 Unsaved Changes first.
- Keep editing, or dismissal of D01, stays at N05 without navigating.
- Discard changes restores previously saved appearance, then allows navigation to N04.
- If appearance changes were explicitly saved first, the image link can proceed using saved appearance. The existing ordinary Save route still returns to N03; reopening N05 uses saved preferences.
- Returning from N04 to N05 displays current saved appearance and refreshed saved imagery.
- Canceling image selection does not replace an existing saved image.
- No second image editor, automatic appearance save or new confirmation dialog is added.

This routing is recorded in the specification, F08 and directly affected return behavior, the Markdown/Mermaid map, P0.2-07/P0.2-10 and traceability.

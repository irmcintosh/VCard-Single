Create one record per test activity using the template in section 3. Assign test identifiers only after the owner authorizes the scope. Allowed status values:

- **OPEN / NOT EXECUTED:** no activity run; current state for FG-01 through FG-07.

- **FAIL:** expected criteria were not met; preserve the failure evidence and stop before changing requirements.

“PASS” is a test result label, not a feasibility-gate closure or approval. No test result authorizes implementation, changes to P0.1–P0.4, matrix reduction, dependency selection or phase advancement. Do not include production personal data, private keys, credentials, personal file paths or sensitive URIs in this register or attached logs.

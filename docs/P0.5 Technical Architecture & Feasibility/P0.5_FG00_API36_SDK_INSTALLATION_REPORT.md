## 3. Installation Method and Outcome

The installed `sdkmanager.bat` emits a deprecation notice and delegates to the already-installed Android CLI. Its wrapper rejects unknown options. The existing backend's help explicitly supports `--ignore-outdated-xmls`, which prevents updates to other packages' XML files.

For that reason, installation invoked the same SDK Manager backend directly, pinned to the discovered revision, without installing any new command-line tools:

```powershell
$sdk = Join-Path $env:LOCALAPPDATA 'Android\Sdk'
& (Join-Path $sdk 'cmdline-tools\latest\bin\android.exe') "--sdk=$sdk" sdk --ignore-outdated-xmls install 'platforms/android-36@2.0.0'
```

Actual result:

```text
INSTALL_EXIT=0
```

Stdout/stderr was captured in a session-local installation log. Only the requested platform was named; no update-all, sources, system image, Build Tools, Gradle, Kotlin, Studio or JDK installation was requested.
